# Crypto Macro sources

Reviewed 2026-10-02. Production enablement is per series and remains disabled unless public display, storage and attribution rights are confirmed.

| Provider / dataset | Endpoint | Intended metric | History / rate limit | Attribution and rights | Storage | Status |
|---|---|---|---|---|---|---|
| ECB statistics, euro reference rates | `https://data-api.ecb.europa.eu/service/data/EXR/` | FX reference context | Daily business-day observations; keyless SDMX API; production refresh fetches USD/EUR, GBP/EUR and JPY/EUR series separately | ECB policy says publicly released statistics may be reused commercially when the source is quoted and metadata is not modified. [Usage policy](https://www.ecb.europa.eu/stats/ecb_statistics/governance_and_quality_framework/html/usage_policy.en.html), retrieved 2026-10-02 | Persistable snapshots with source timestamps | **Enabled and persisted: USD/EUR, GBP/EUR, JPY/EUR** |
| CoinLore public crypto API | `https://api.coinlore.net/api/` | BTC, ETH, BTC dominance | 365-day OHLCV documented; recommends about 1 request/sec | API page describes free public use, but [Terms](https://www.coinlore.com/terms-of-use) prohibit copying, redistribution or commercial use without express written consent. Retrieved 2026-10-02 | No persistence or display until permission | **Unconfirmed / disabled** |
| CoinGecko API | `https://pro-api.coingecko.com/api/v3/` | BTC, ETH, global cap and stablecoin proxy | Demo 10k calls/month, 100/min; historical depth depends on plan | Paid plans advertise commercial use with attribution; no paid plan is approved. [Pricing](https://www.coingecko.com/en/api/pricing), [license conditions](https://support.coingecko.com/hc/en-us/articles/16760512207257-What-Are-the-Differences-Between-Commercial-and-Custom-Licenses), retrieved 2026-10-02 | Disabled until licensed | **Unconfirmed / disabled** |
| FRED Nasdaq / S&P / VIX | `https://api.stlouisfed.org/fred/series/observations` | Equity and volatility context | Up to 120 requests/minute; series-specific history | FRED says third-party copyrights and redistribution restrictions remain. Nasdaq and S&P notes require permission; VIX is Cboe-owned. [FRED terms](https://fred.stlouisfed.org/legal/terms/), retrieved 2026-10-02 | No persistence | **Licensing-gated / disabled** |
| U.S. Treasury daily yield curve | `https://home.treasury.gov/treasury-daily-interest-rate-xml-feed` | 2y / 10y yields | Daily published feed from 1990 | Feed is public but site terms and any redistribution conditions must be confirmed for this product. Retrieved 2026-10-02 | Disabled until confirmed | **Unconfirmed / disabled** |
| Alpha Vantage Gold | `https://www.alphavantage.co/query?function=GOLD_SILVER_HISTORY` | Gold | Free service generally 25 requests/day | Terms describe personal, non-commercial use unless separately agreed. [Terms](https://www.alphavantage.co/terms_of_service/), retrieved 2026-10-02 | No persistence | **Unconfirmed / disabled** |

The dashboard never substitutes a proxy silently. A broad dollar index is not called DXY, and USDT + USDC market capitalization is not called total stablecoin supply.
